## 是什么

[Feishu Move](https://openasf.space)（飞书迁移助手）是一个 **本地优先的个人飞书账号迁移工具**。它把你有权迁移的个人内容，从 A 公司的飞书账号复制并重建到 B 公司的飞书账号。每一步都在本地运行，每一处差异都可解释。

## 为什么做

换公司时，个人飞书里的文档、知识库、表格、文件、聊天记录全丢在旧租户里，手动导出再导入既慢又容易丢数据。Feishu Move 用「源端只读 + 本地运行 + 冲突不覆盖 + 全程可核验」四条铁律，把迁移变成一个可信的、可审计的自动化流程。

## 核心原则

- **源端只读** —— 策略层、命令层、测试层三重锁死，绝不往 A 侧写入
- **本地运行** —— 只监听 `127.0.0.1`，凭证不上传、不落日志
- **冲突不覆盖** —— 冲突升级给人判断，不自动覆盖任何数据
- **全程可核验** —— 每一步有状态、有检查点、可追溯

## 能迁什么

| 类别 | 能力 |
|---|---|
| 文件 | 跨租户复制重建，字节级 SHA-256 一致性校验 |
| 文档 | 正文原生往返，图片走媒体重传管线 |
| 知识库 | 保留节点与 obj_type，正文经 docx 路径迁移 |
| 表格 | 值矩阵逐单元格一致，公式回退为值 |
| 多维表格 | 迁移记录与单选选项 |
| 协作者 | 已验证协作者写入，未匹配人员按接收方策略处理 |
| 聊天 | 生成自包含 HTML + JSON 归档包 |

## 你能怎么用

通过 WorkBuddy SkillHub 安装，或 `npm install -g feishu-move-cli`，连接 A/B 两端飞书 CLI 配置，扫描 → 规划 → 执行 → 核验 → 解决冲突，最后下载验证报告。适合从一家公司离职、需要把个人飞书资产带走的任何人。
