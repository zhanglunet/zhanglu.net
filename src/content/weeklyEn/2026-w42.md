## The through-line: make trends more than an outbound link

New GitHub projects surface every day, but merely seeing them rarely turns into an actionable improvement. This week, the personal site added public entry points for `trend-workflow`: an explanation of how trend signals can enter a repository-improvement process now appears in navigation, the writing index, and the Skills index.

This is not a claim that an unverified outcome has shipped. What is public is the workflow's introduction, discovery path, and installation method. The workflow description itself makes its boundary clear: automation may generate a PRD, decompose work, and open a PR, but it never merges one automatically.

## Start with navigation: a route for readers in both languages

The global Header now includes a trend link after “Weekly”: it reads “趋势” in Chinese and “Trends” in English, and both point to [trend.zhanglu.net](https://trend.zhanglu.net/).

Supporting that outbound link meant extending the navigation data from internal routes only to allow either an internal `base` or an explicit `href`. The built output was checked for both the Chinese and English home pages, confirming that each renders the intended link rather than leaving one language with an isolated entry point.

## Put methodology and access where they can be found

The writing index gained bilingual entries for “Turning GitHub Trends into Actionable Repo Improvements: The End-to-End Workflow.” The guide presents a clear chain: trend collection and growth-factor analysis, alignment with a repository, PRD generation, task decomposition, and opening a PR.

The Skills index now also features `trend-workflow`. Its entries provide the website, Skill page, workflow guide, open-source repository, and the installation command `npx skills add zhanglunet/trend-workflow`. Chinese and English entries were added together so the same workflow is discoverable from both language paths.

## Keep the public claim within the delivery boundary

Repository history verifies that the site content, links, and bilingual indexes were committed, and that the navigation change passed local build verification. This report does not infer that the external workflow has run against a particular repository, nor does it present generated drafts or unmerged PRs as completed results.

> This week in one line: turning trends into action begins not with one more ranking page, but with putting the entry point, the explanation, and a usable tool on the same path.
