## 这一周的主线：让趋势不止是一条外链

GitHub 上每天都会出现新的热门项目，但“看见”本身很难变成可以执行的改进。本周，个人站为 `trend-workflow` 补齐了公开入口：它把趋势信息如何进入自有仓库改进流程的说明，放进导航、文章索引和 Skills 索引三个读者会实际经过的位置。

这不是把一个尚未验收的结果包装成发布。站上公开的是工作流的介绍、使用入口和安装方式；工作流说明本身明确写出，自动化可生成 PRD、拆分任务并创建 PR，但不会自动合并。

## 从导航开始：中英文读者都能找到趋势入口

全站 Header 在“周报 / Weekly”之后新增了趋势入口，中文显示为“趋势”，英文显示为“Trends”，均直接指向 [trend.zhanglu.net](https://trend.zhanglu.net/)。

为支持这个外链，导航数据从只接受站内路由扩展为同时接受站内 `base` 与显式 `href`。构建产物已分别检查中文和英文首页，确认两种语言都输出了正确的链接，而不是只在某一侧出现一个孤立入口。

## 把方法论和使用方式放到可检索的位置

文章索引新增双语条目，指向工作流长文《把 GitHub 趋势变成自己仓库的改进：工作流介绍》。它把流程公开为一条清晰的链路：从趋势抓取、流行因素拆解，到和自有仓库对齐、生成 PRD、拆解任务与开 PR。

同时，Skills 索引新增并精选了 `trend-workflow`。页面给出官方网站、技能页、方法论长文、开源仓库，以及 `npx skills add zhanglunet/trend-workflow` 的安装命令。中文与英文条目一同进入内容集合，保证两个语言入口都能检索到同一个工作流。

## 公开表述保留交付边界

本周仓库历史能够验证的是站点内容、链接和双语索引已经提交，且导航改动在本地构建中通过验证。周报不据此推断外部工作流已经在任何具体仓库中执行，也不把自动生成的草稿或尚未合并的 PR 当作已完成成果。

> 本周的一句话总结：把趋势变成行动，第一步不是多看一页榜单，而是把入口、解释和可用的工具放在读者能找到的同一条路上。
