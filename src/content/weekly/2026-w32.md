## 这一周的主线：把项目入口和内容入口补成一套

W32 没有继续横向铺开很多新能力，而是把已经存在的项目和工具整理成更完整的公开入口：项目页、文章页、npm 使用说明和周报归档彼此连起来，让人和 agent 都能从站点找到下一步。

## 补齐公开周报归档

先把站点缺失的 W30、W31 周报补回中英文两侧，并接入现有的 weekly collection、详情页和 JSON API。周报继续以 Git 历史和 `docs/dev-log` 为事实来源，不把计划写成已完成的交付。

这次回补也把「周报是站点内容的一部分」这条链路重新跑通：内容文件、双语镜像、页面路由和机读端点使用同一份 schema。

## 新增两个项目入口

本周把两个已有站点纳入项目列表：

- **模力自由港 / FreeModel Port**：面向本地 Agent 的免费模型目录与统一路由入口，公开目录只负责产生候选，实际调用结果才决定模型是否可运行。
- **OpenWorker 中文站**：为 Andrew Ng 的开源 OpenWorker 提供中文侧、本地化构建和源码分析；项目页明确区分上游项目、本项目维护的中文构建，以及源码研究内容。

两个项目都补了中文、英文、详情页入口、封面和 JSON 数据，并保留了各自的限制说明：统一路由仍需谨慎处理权限，本地优先不等于绝对不出网，OpenWorker 当前构建也不等于生产级保证。

## npm / CLI 专页上线

站点新增 `/npm` 与 `/en/npm` 专页，把 `zhanglu-net` 的安装、`npx` 用法、命令分类和 agent 使用场景集中说明。页面同时提醒不要把本站 CLI 与 npm 上另一个同名的 `zhanglu` 包混淆。

这让 `/agents` 里的简要介绍有了明确的深入阅读入口，也让 CLI、JSON API、`llms.txt` 和站点导航形成了更清晰的分层。

## 两篇双语长文补齐项目背景

围绕本周两个项目各补了一篇中文和英文长文：

- FreeModel Port：从「免费模型清单」这个抽象出发，解释公开目录、真实请求、统一路由和流式 fallback 之间的取舍。
- OpenWorker 中文站：说明本地化不只是翻译，还包括独立更新通道；同时记录 TurnEngine 的并发读取、串行写入和权限边界。

本周的结论：个人站的价值不只在于列出做过什么，还在于把项目归属、使用入口、限制条件和可机读接口一起交代清楚。内容越多，边界越要写在页面里。
