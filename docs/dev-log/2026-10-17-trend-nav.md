# 2026-10-17 · 导航增加趋势雷达 (trend.zhanglu.net) 入口

## 目标

在全站 Header 导航中增加 `https://trend.zhanglu.net/` 入口，支持中英双语切换。

## 改动

1. **`src/i18n/ui.ts`**：
   - 中文词典 `zh` 增加 `'nav.trend': '趋势'`（与周报、文章等两字节奏保持一致）。
   - 英文词典 `en` 增加 `'nav.trend': 'Trends'`（与 Projects, Decks, Skills 等复数名次保持一致）。
2. **`src/components/Header.astro`**：
   - `nav` 数组支持显式 `href`（绝对外链）与 `base`（站内路由）。
   - 在「周报 / Weekly」后加入 `{ href: 'https://trend.zhanglu.net/', key: 'nav.trend' }`。
   - 渲染时优先使用 `item.href`，若为站内路由则调用 `localizePath(item.base, lang)`。

## 验证

- 执行 `pnpm run build`：191 个页面全部成功构建通过。
- 检查 `dist/index.html`（中文版首页）：Header 导航正确输出 `<a href="https://trend.zhanglu.net/" ...> 趋势 </a>`。
- 检查 `dist/en/index.html`（英文版首页）：Header 导航正确输出 `<a href="https://trend.zhanglu.net/" ...> Trends </a>`。
