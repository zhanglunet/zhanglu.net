## 踩坑

- **自己做的语言自适应把截图坑了**：Playwright 默认 locale 是 `en-US`，截 `/` 时被自适应脚本
  跳到 `/en/` —— 中英两张截图内容几乎一样（文件大小 837814 vs 837831 露了馅）。
  修法：截图时显式给 context 设 `locale`（zh 页用 `zh-CN`），并**打印最终 URL 确认没被重定向**。
  以后任何针对本站的自动化截图 / 抓取都要注意这条。
- Markdown 语法（`**bold**`）写进 `.astro` 模板不会渲染，会显示字面星号 —— 得用 `<strong>`。
