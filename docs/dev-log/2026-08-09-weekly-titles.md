# 2026-08-09 · 重写周报标题

## 背景

周报列表页的每周标题都使用「本周做了什么」，信息密度低，也无法让读者快速判断每周最重要的交付。

## 改动

为 W29–W32 分别提炼主线成果，并同步更新中文与英文 frontmatter 标题：

- W29：三个产品大版本与决策智能体的组织系统方向。
- W30：个人站从中文作品集升级为双语、机读的网站系统。
- W31：修复公开内容边界后，再扩展项目与长文内容。
- W32：把项目、文章、CLI 和周报归档连成可发现的入口。

只调整标题，不改周报正文、日期、摘要或路由 slug。

## 验证

执行 `pnpm run build`，确认双语周报页面和 API 仍正常生成；执行 `git diff --check` 检查格式。
